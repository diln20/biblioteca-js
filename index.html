🏁 Proyecto final desde cero · Directorio de usuarios

Con este proyecto juntas todo lo aprendido: petición GET, estado de carga, validación de respuesta, JSON, manejo de errores, DOM y búsqueda.

1. Crea index.html, style.css y app.js.
2. En HTML crea un botón, un buscador y un contenedor.
3. En JavaScript consulta /users con fetch.
4. Verifica response.ok y convierte con response.json().
5. Recorre el array y crea tarjetas con DOM.
6. Filtra los usuarios mientras se escribe en el buscador.
7. Si hay error, muestra un mensaje visible en la interfaz.

Meta: que el estudiante pueda explicar de dónde salen los datos, qué parte espera la red y qué ocurre si la API falla.
