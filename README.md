# API JS Academy

Biblioteca educativa enfocada **únicamente en APIs con JavaScript**, pensada para estudiantes que están empezando.

## Ruta pedagógica

1. Qué es una API
2. HTTP: métodos y códigos de estado
3. JSON
4. Primer `fetch()` GET
5. `response.status` y `response.ok`
6. Promesas, `.then()` y `async/await`
7. `try/catch`, carga y errores
8. Mostrar datos de la API en el DOM
9. Query parameters
10. POST
11. PUT y PATCH
12. DELETE
13. Headers y autenticación
14. CORS
15. `Promise.all`
16. Cancelación con `AbortController`
17. Depuración con DevTools
18. Estructura mínima de un proyecto
19. Proyecto final: directorio de usuarios

## Incluye

- Explicaciones en lenguaje sencillo.
- Código copiable.
- Panel “Así se ve / qué ocurre”.
- Ejercicio corto por lección.
- Mini proyecto por lección.
- Progreso guardado con `localStorage`.
- Buscador y filtro por tema.
- Explorador de API integrado.
- Proyecto final funcional con JSONPlaceholder.
- Diseño responsive y modo claro/oscuro.

## Ejecutar localmente

Puedes abrir `index.html` directamente. Para una experiencia más parecida a un proyecto real, puedes usar Live Server.

## API usada para prácticas

La mayoría de ejemplos usan JSONPlaceholder porque ofrece recursos de prueba para practicar GET, POST, PATCH y DELETE sin trabajar con datos reales.

> Nota: JSONPlaceholder simula las escrituras; los cambios no se persisten permanentemente.

## Publicación

El repositorio incluye un workflow de GitHub Pages que publica el contenido estático desde la rama `main`.
