# Biblioteca JavaScript

Biblioteca educativa interactiva de JavaScript con estética neón.

## Contenido

Incluye fundamentos, variables, tipos, operadores, condicionales, bucles, funciones, arrays, objetos, scope, closures, DOM, eventos, formularios, JSON, promesas, async/await, fetch, manejo de errores, localStorage, clases, módulos y buenas prácticas.

También incorpora buscador, filtros, actividades, código copiable y un editor HTML + CSS + JavaScript en vivo.

## Uso

Abre `index.html` directamente en el navegador o usa Live Server.
